# Better Coffee

Sitio web de Better Coffee (café funcional en lata).

## Estructura
- `index.html`: la página (HTML estático).
- `assets/styles.css`, `assets/app.js`: estilos, textos EN/ES, datos de producto e interacciones.
- `assets/img/`, `assets/fonts/`: latas, ingredientes y tipografías (Anton, Inter).

## Publicar
**Vercel:** conecta este repositorio en vercel.com → "Add New..." → "Project" → importa `mosheacrich-art/BetterCoffee`. Framework Preset: "Other". Sin comando de build ni carpeta de output; Vercel sirve `index.html` directamente desde la raíz.

**GitHub Pages:** Settings → Pages → Branch: `main`, carpeta `/ (root)`.
